Comandos ZPL II (Zebra)

ComandoDescrição
^XA ... ^XZInício e fim do formato da etiqueta
^PW800 / ^LL400Largura e altura da etiqueta em dots
^FOx,yPosição de origem do campo (X, Y)
^A0N,h,wFonte escalável Zebra (altura, largura)
^FD...^FSDados do texto ou código de barras
^GBw,h,t,c,rCaixa ou linha gráfica (largura, altura, espessura)
^FRImpressão reversa (branco sobre preto)
^BYw,r,hPadrão de largura de módulo e altura de barras
^BCN,h,Y,NCódigo de barras Code 128
^BEN,h,Y,NCódigo de barras EAN-13
^BQN,2,magQR Code 2D (ex: ^FDQA,texto^FS)

ComandoDescrição

ESC/POS (COM/POS Fiscal)

ComandoDescrição
ESC @ / WIDTH 80Inicializa impressora / Define bobina (80mm ou 58mm)
ESC a 0|1|2Alinhamento: 0=Esquerda, 1=Centro, 2=Direita
ESC E 1 / ESC E 0Ativa / desativa texto em negrito (enfatizado)
ESC - 1 / ESC - 0Ativa / desativa modo sublinhado
GS ! 17 / GS ! 0Texto expandido (dupla altura/largura) / Normal
ESC M 1 / ESC M 0Fonte B condensada (menor) / Fonte A padrão
GS B 1 / GS B 0Impressão reversa (fundo preto, texto branco)
<LR>Esq|DirAlinha texto à esquerda e valor à direita na bobina
BARCODE CODE128 "x"Imprime código de barras 1D (GS h, GS w, GS H)
QRCODE 5 "dados"QR Code Fiscal SEFAZ NFC-e / SAT / PIX (GS ( k)
GS V 66Aciona guilhotina (corte parcial/total do cupom)

ComandoDescrição
